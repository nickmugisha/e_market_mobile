# e-market — Submission checklist

Before handing the project to the professor or copying it to another computer:

- [ ] LOT 10 `FINAL LOCAL QA PASSED`.
- [ ] Git working tree is clean.
- [ ] Latest commits are visible with `git log --oneline`.
- [ ] `firebase_options.dart` is present.
- [ ] `firebase.json` and `firestore.rules` are present.
- [ ] `README.md` is present.
- [ ] `DEMO_SCRIPT.md` is present.
- [ ] `FINAL_PHONE_TEST_CHECKLIST.md` is present.
- [ ] The debug APK exists after the final build:
      `build\app\outputs\flutter-apk\app-debug.apk`.
- [ ] Do not include temporary `.lot*_backup_*` directories.
- [ ] Do not include `build/` if the professor requests source code only.
- [ ] Do not change Firebase project/billing configuration before the demo.
- [ ] Keep one clean client account ready.
- [ ] Keep at least one clean seller account ready.
- [ ] Prefer two seller accounts if demonstrating mixed-seller cart protection.
- [ ] Keep 2–3 active products with visible stock for the demo.
- [ ] Keep at least one product image small enough to demonstrate editing.
- [ ] Test the presentation phone with internet before the exam.
- [ ] Complete `FINAL_PHONE_TEST_CHECKLIST.md` when a phone is available.
